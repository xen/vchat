# АС «ВБУДУЩЕЕ» — Сервис «ИИ-агент-чат-бот»

Добро пожаловать в репозиторий проекта АС «ВБУДУЩЕЕ». Это интеллектуальная платформа для создания и интеграции чат-ботов, использующая технологию RAG (Retrieval-Augmented Generation) для предоставления точных ответов на основе внутренних материалов и документов Заказчика.

---

### 🚀 Ключевые возможности

- **Интеллектуальный поиск:** Быстрый семантический поиск по базе знаний с использованием `PGVector`.
- **Интеграция с GigaChat:** Использование моделей GigaChat (версии 2 MAX и выше) для генерации ответов.
- **Обязательное цитирование:** Автоматическое формирование ссылок на исходные документы (Word, Excel, PDF, PPTX) под каждым ответом.
- **Бесшовное внедрение:** Готовый веб-виджет для интеграции в портал на платформе Битрикс.
- **Высокая нагрузка:** Поддержка более 1000 одновременных пользовательских сессий.

---

### 🛠 Технологический стек

- **Backend:** Python (использование PHP строго запрещено).
- **ИИ-модуль:** GigaChat API (через защищенное SSL-соединение).
- **Database:** PostgreSQL (с расширением `pgvector`).
- **Оркестрация:** Docker, совместимость с Kubernetes.
- **Monitoring:** Prometheus, Grafana, JSON-логирование.

---

### 📂 Структура репозитория

- `vchat/` — Исходный код серверной части (API, RAG-конвейер).
- `vchat/docs/` — Актуальная техническая и эксплуатационная документация.
- `vchat/jobs/` — Фоновые задачи (краулер, эмбеддер).
- `vchat/frontend/` — Исходный код административной панели.
- `vchat/frontend_chat/` — Исходный код фронт-виджета для АС «ВБУДУЩЕЕ».
- `vchat/docker/` — Конфигурации для контейнеризации и Docker-образы.
- `vchat/migrations/` — Миграции базы данных (Alembic).
- `deploy/` — Конфигурации для CI/CD (GitLab). (находится в корне проекта или в процессе создания)
