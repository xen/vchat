# Метрики `vchat`

Дата проверки: 2026-06-10.

Эндпоинт: `GET /metrics`.

## Метрики `Prometheus`

| Область из плана               | Метрика                                         | Тип         | Комментарий                                                                                                                 |
| ------------------------------ | ----------------------------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------- |
| Время ответа чат-бота          | `vchat_chat_response_duration_seconds`          | Гистограмма | Полная длительность обработки веб-сокет сообщения от получения пользовательского текста до завершения обработки или ошибки. |
| Одновременные сессии           | `vchat_active_chats`                            | Датчик      | Считается как размер набора `Redis` `active_chats`, который обновляется при подключении и закрытии чата.                    |
| Ошибки чата                    | `vchat_chat_requests_total{status=...}`         | Счетчик     | Есть статусы `ok`, `internal_error`, `provider_http_error`, `guardrail_blocked_input`, `guardrail_blocked_output`.          |
| Использование модели           | `vchat_chat_tokens_total{provider,model}`       | Счетчик     | Суммирует токены из событий использования, которые возвращает поток модели.                                                 |
| Проверки безопасности          | `vchat_chat_guardrail_events_total{reason=...}` | Счетчик     | Считает причины срабатываний проверок безопасности.                                                                         |
| Размер контекста               | `vchat_chat_context_chunks`                     | Гистограмма | Считает количество чанков, переданных в контекст ответа.                                                                    |
| Статус обходчика               | `vchat_crawler_pages_total{result=...}`         | Счетчик     | Считает результаты запуска обходчика: `new`, `changed`, `unchanged`, `error`, `excluded`.                                   |
| Скорость синхронизации         | `vchat_crawler_run_duration_seconds`            | Гистограмма | Считает длительность запуска обходчика по `CrawlRun.started_at/finished_at`.                                                |
| Последняя синхронизация        | `vchat_crawler_last_crawl_timestamp_seconds`    | Датчик      | Временная метка последнего успешно завершенного запуска обходчика по источнику.                                             |
| Ограничение частоты            | `vchat_crawler_rate_limited_total`              | Счетчик     | Считает запуски обходчика, где `was_rate_limited=True`.                                                                     |
| Состояние очереди `Celery`     | `vchat_celery_queue_size`                       | Датчик      | Длина очереди `Celery` по умолчанию из брокера `Redis`.                                                                     |
| Состояние очереди векторизации | `vchat_embedder_queue_size`                     | Датчик      | Длина очереди `embeddings` из брокера `Redis`.                                                                              |
| Состояние очереди обходчика    | `vchat_crawler_queue_size`                      | Датчик      | Длина очереди `crawler` из брокера `Redis`.                                                                                 |

Дополнительно `prometheus_client` автоматически экспортирует стандартные
метрики среды выполнения `Python`, сборщика мусора и платформы, если они включены
в реестр.

## Логирование

| Область из плана        | Что есть сейчас                                                                                                              | Комментарий                                                                                                                                                                                                                                                                         |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Связь с документами     | В истории чата сохраняются использованные чанки; в финальном веб-сокет событии отправляются `sources`, `coverage`, `policy`. | Данные ответа и источников сохраняются в истории чата.                                                                                                                                                                                                                              |
| Логирование запроса     | Структурированное событие `chat_user_request`.                                                                               | Поля: `provider`, `model`, `tokens`, `chunks_count`, `response_size`, `response_chars`, `guardrail_status`, `guardrail_triggered`, `guardrail_reasons`, `prompt_chars`, `prompt_bytes`, `user_prompt_chars`, `user_prompt_bytes`, `messages_count`, `status`, `chat_id`, `user_id`. |
| Форматтер `JSON`        | `JsonLogFormatter` и `log_json(...)`.                                                                                        | Формат включается через конфиг `log_format`.                                                                                                                                                                                                                                        |
| Логи запросов обходчика | Структурированное событие `crawler_external_request`.                                                                        | Поля: `url`, `http_status`, `access_time`, `method`, `elapsed_seconds`, `source_id`, `spider`.                                                                                                                                                                                      |
