# Руководство пользователя vchat

## Настройки источника

Страница настроек источника используется для управления тем, как vchat обходит
сайт, какие страницы сохраняет в базу знаний и какие URL исключает из индекса.

Откройте административный интерфейс и перейдите в раздел **Источники**. В списке
источников выберите нужный сайт и откройте его настройки.

На странице настроек доступны основные параметры:

- адрес источника;
- задержка и таймаут обхода;
- учет `robots.txt`;
- правила обхода и исключения URL;
- расписание автоматической переиндексации.

## Правила обхода

Правила помогают убрать технические, повторяющиеся или ненужные варианты URL из
базы знаний.

Используйте правило **Игнорируемый параметр**, когда параметр в query string не
меняет основной смысл страницы. Например, параметры аналитики `utm_source` или
возрастной фильтр `age` на сайте, где разные значения ведут к одному и тому же
основному материалу.

После добавления такого правила vchat будет нормализовать новые найденные URL:

```text
https://example.com/article/?age=14-16
```

будет обрабатываться как:

```text
https://example.com/article/
```

Используйте правило **Регулярное выражение URL**, если нужно оставить в обходе
только определенную ветку сайта или исключить лишние разделы через шаблон.

## Сохранение настроек и переиндексация

После изменения настроек нажмите кнопку сохранения на странице источника.
Сохранение применяет новые правила к конфигурации источника, но само по себе не
гарантирует, что вся база найденных страниц уже перестроена.

Чтобы изменения отразились в базе знаний, после сохранения настроек нажмите
кнопку обновления или переиндексации источника. Это запустит повторный обход
источника, применит новые правила к найденным страницам и обновит поисковый
индекс.

Это особенно важно после изменения правил URL. Например, если вы добавили
параметр `age` в список игнорируемых, нужно запустить переиндексацию источника,
чтобы старые варианты страниц с `?age=...` перестали использоваться как
отдельные источники ответа.

## Проверка результата

После запуска переиндексации дождитесь завершения фоновой задачи. В списке
источников и страниц проверьте, что:

- источник не находится в состоянии ошибки;
- нужные базовые страницы остались доступными для поиска;
- технические варианты URL больше не используются как отдельные активные
  страницы;
- новые ответы в чате показывают источники уже по обновленным правилам.
