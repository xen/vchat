# Конфигурация ресурсов АС «ВБУДУЩЕЕ» на Cloud.ru

## 1. Тестовая среда (Dev/Test)

Предназначена для функционального тестирования, отладки RAG-конвейера и первичной индексации небольшого объема документов.

| Компонент | Сервис Cloud.ru | Спецификация (минимально) |
|---|---|---|
| Backend API | Evolution Container Apps | 1 реплика: 1 vCPU / 2 ГБ RAM |
| Indexer (Celery) | Evolution Container Apps | 1 реплика: 1 vCPU / 4 ГБ RAM |
| Vector DB | Managed PostgreSQL | 2 vCPU / 4 ГБ RAM, 20 ГБ SSD |
| S3 Storage | Evolution Object Storage | Стандартный тариф, до 10 ГБ |
| AI Модели | GigaChat API | Модель Lite/Pro (для тестов) |

## 2. Промышленная среда (Production)

Рассчитана на 1000+ одновременных сессий, высокую отказоустойчивость и соблюдение SLO по времени ответа (P90 < 20 сек).

### Вычислительные мощности (Compute)

- **Backend API:** 3 реплики по 2 vCPU / 4 ГБ RAM каждая. Обеспечивают стабильную потоковую выдачу (streaming) и балансировку нагрузки.
- **Indexer (Celery):** 2 реплики по 2 vCPU / 8 ГБ RAM. Необходимы для тяжелых задач парсинга PDF и PPTX документов.

### База данных (Managed PostgreSQL + PGVector)

- **Процессор:** 4 vCPU.
- **Память:** 16 ГБ RAM (минимум). Важно для удержания индекса HNSW в оперативной памяти.
- **Диск:** 100 ГБ+ NVMe SSD. Высокая скорость IOPS критична для семантического поиска.
- **Отказоустойчивость:** Рекомендуется конфигурация Master + Replica.

### Хранилище и сеть

- **S3 Storage:** Evolution Object Storage (от 50 ГБ) для архива материалов.
- **Секреты:** Cloud.ru Secret Manager для безопасного хранения ключей GigaChat API.
- **Мониторинг:** Managed Prometheus & Grafana для контроля Golden Signals.

## 3. Резюме по тарификации (Cloud.ru Evolution)

Использование сервисов линейки Evolution позволяет оптимизировать затраты за счет модели Pay-as-you-go (оплата только за потребленные ресурсы).

Для Production-среды рекомендуется использовать Managed Service for Kubernetes, если планируется дальнейшее масштабирование количества агентов.

Для простых задач на старте достаточно Evolution Container Apps, что снижает затраты на администрирование инфраструктуры.
