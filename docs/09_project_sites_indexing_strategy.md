# Стратегия индексации сайтов проекта для АС «ВБУДУЩЕЕ»

Для организации индексации обширного списка сайтов в рамках АС «ВБУДУЩЕЕ», необходимо применить системный подход, разделяющий ресурсы по технологическому стеку и типу контента. Это позволит выполнить требования ТЗ по производительности и точности ответов ИИ-агента.

## 3. Технический план подготовки (Pre-indexing)

### Шаг 1: Очистка контента (Normalization)

Перед отправкой в GigaChat необходимо очистить контент от «шума»:
*   Удаление навигационных меню, футеров и рекламных баннеров, которые дублируются на всех 30+ сайтах.
*   Извлечение только основного текста (Main Content Extraction), чтобы избежать замусоривания векторной базы данных.

### Шаг 3: Безопасность и доступ

Поскольку многие сайты (напр., Грантовая платформа `grant.vbudushee.ru`) могут содержать закрытые данные, необходимо убедиться, что краулер имеет доступ только к публичным разделам. Все обращения краулера должны логироваться в системе мониторинга АС «ВБУДУЩЕЕ».

**Рекомендация по организации:**

В проекте будет единый реестр источников в административном интерфейсе, где будет возможность мониторить какой контент был проиндексирован, как сформировалось его внутреннее представление для индексатора. Рекомендуется регулярно проверять состояние индекса и анализировать доступность документов для доступа пользователей.
