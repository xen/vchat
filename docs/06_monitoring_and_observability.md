# План наблюдаемости (Monitoring & Observability)

**Проект:** Сервис «ИИ-агент-чат-бот» для АС «ВБУДУЩЕЕ»
**Статус:** Отчетная документация (Этап 1)

## 1. Введение
Наблюдаемость системы АС «ВБУДУЩЕЕ» необходима для обеспечения стабильной работы RAG-конвейера, контроля качества ответов ИИ и соблюдения требований безопасности. План базируется на сборе метрик в формате Prometheus и структурированном логировании в формате JSON.

## 2. Ключевые метрики (Prometheus Metrics)
Согласно ТЗ, общее число метрик на один контейнер не должно превышать 1000 единиц.

### 2.1. Производительность и SLO (Golden Signals)
*   **Latency (Время ответа):** Общее время формирования ответа чат-бота (целевой показатель — менее 20 секунд для 90-го процентиля).
*   **Traffic (Нагрузка):** Количество одновременных пользовательских сессий (цель — 1000+).
*   **Errors (Ошибки):** Частота и доля ошибок (HTTP 5xx, таймауты API).
*   **Availability (Доступность):** Статус доступности сервиса и AI-агента.

### 2.2. Метрики RAG и GigaChat
*   **LLM Usage:** Расход токенов GigaChat API и лимиты сессий.
*   **Search Quality:** Размер контекста (количество чанков) и связь с исходными документами.
*   **Vector DB Latency:** Скорость выполнения семантического поиска в векторной базе данных.
*   **Inference TTFT:** Время до генерации первого токена в потоковом режиме.

### 2.3. Индексация и хранилище
*   **Sync Speed:** Скорость индексации и переиндексации файлов из хранилища Заказчика.
*   **Storage Health:** Объем индексируемых данных и остаток дискового пространства.
*   **Crawler Status:** Количество успешно обработанных документов (Word, Excel, PDF, PPTX) и ошибки парсинга.

## 3. Логирование и аудит безопасности

### 3.1. Структура логов
*   **Формат:** Все логи выводятся в формате JSON для автоматизированной обработки.
*   **Обязательные поля:** ID пользователя (`personalID`), ID сессии, уникальный идентификатор запроса (`Trace ID`), результат ответа.

### 3.2. События ИБ (Security Logging)
*   **Prompt Logs:** Все обращения к GigaChat, включая входящие промпты (с маскированием ПДн).
*   **Audit Trail:** Попытки НСД, ошибки аутентификации, изменения прав доступа администраторами.
*   **Guardrails Events:** Срабатывание фильтров безопасности и классификатора релевантности.

## 4. Правила оповещений (Alerting Rules)

Оповещения настраиваются в Prometheus Alertmanager работающий на инфраструктуре Заказчика с отправкой уведомлений на служебную почту Фонда.

### 4.1. Критические алерты (Красный уровень)

| Событие             | Условие (Trigger)                             | Канал           |
| :------------------ | :-------------------------------------------- | :-------------- |
| **Service Down**    | Контейнер недоступен (Up == 0)                | Почта (Instant) |
| **API Error Spike** | Доля ошибок > 5% за 2 минуты                  | Почта (Instant) |
| **SLO Violation**   | 90-й процентиль ответа > 20 сек               | Почта (Instant) |
| **Security Breach** | Выявление критической уязвимости или инъекции | Почта / SOC     |

### 4.2. Предупреждающие алерты (Желтый уровень)

| Событие              | Условие (Trigger)                        | Канал |
| :------------------- | :--------------------------------------- | :---- |
| **Token Exhaustion** | Прогноз исчерпания бюджета токенов < 24ч | Почта |
| **Sync Stalled**     | Отсутствие обновлений в индексе > 12ч    | Почта |
| **Disk Space Low**   | Заполнение диска > 85%                   | Почта |

## 5. Инструментарий и дашборды
Согласно требованиям к среде развертывания Заказчика:
*   **Prometheus:** Сбор метрик через эндпоинт `/metrics`.
*   **Grafana:** Дашборды для визуализации SLO, состояния GigaChat и процессов индексации.
*   **GitLab:** Мониторинг конвейеров сборки и развертывания.
*   **Централизованный сбор логов:** Просмотр журналов через стандартные средства инфраструктуры Фонда.

## 6. Резюме
Реализация данного плана позволяет Исполнителю гарантировать корректную работу АС «ВБУДУЩЕЕ» и оперативно устранять недостатки в рамках гарантийных обязательств (в течение 5–24 часов для критических и высоких приоритетов).
