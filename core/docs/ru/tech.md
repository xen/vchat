## Технические требования для работы с сервисом

Доступ к сайту осуществляется через базовые интернет протоколы HTTP и HTTPS.

Для доступа к страницам сайта необходимо использовать актуальные версии Google Chrome, Mozilla Firefox и Safari. Обратите внимание, что использование некоторых расширений может частично или полностью заблокировать использование сайта.

Браузер должен иметь разрешения для использования JavaScript и cookie файлов.

Письма отправляемые сервисом отправляются в формате HTML.

Для доставки уведомлений или в случае активации интеграции с другими сервисами могут использоваться другие способы донесения информации. Например, при использовании внешних API предоставляемых третьими лицами.
