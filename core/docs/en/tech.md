## Technical requirements for working with the service

The site is accessed via basic Internet protocols HTTP and HTTPS.

To access the site pages, you must use the latest versions of Google Chrome, Mozilla Firefox and Safari. Please note that using some extensions may partially or completely block the use of the site.

The browser must have permissions to use JavaScript and cookie files.

Emails sent by the service are sent in HTML format.

To deliver notifications or in case of activation of integration with other services, other methods of delivering information may be used. For example, when using external APIs provided by third parties.
