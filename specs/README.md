# Project Task Specs

Здесь хранятся спецификации конкретных задач проекта.

Спека задачи - временный, но сохраняемый рабочий контракт. Она отличается от
`kb/`: `kb/` содержит постоянные правила проекта, а `specs/` сохраняет ход
развития конкретных задач.

## Когда создавать

- Задача широкая с самого начала.
- Маленькая задача начала разрастаться.
- Пользователь просит “сначала продумать”, “сделать план”, “разложить на этапы”.
- Нужно зафиксировать verifier criteria перед реализацией.

## Формат

```md
# Task: Название

## Goal
Какой результат должен быть достигнут.

## Context
- Project KB:
- Global memory:
- Relevant recipes:

## Iterations
1. Шаг и критерий завершенности.
2. Шаг и критерий завершенности.

## Verification Criteria
- Конкретная проверка.
- Конкретный тест или ручная проверка.

## Guard Rails
- Что нельзя менять.
- Какие API и контракты должны сохраниться.
```

## Именование

Используй дату и короткое имя:

```text
specs/2026-06-15-widget-integration-refactor.md
```
