Публичный API VChat

На этой странице собрана краткая инструкция по публичным методам API. Полный документ: docs/02_openapi_specification.md.

  • GET /api/update — обновление индекса по URL документа.

1) Обновление индекса документа

Метод принимает URL документа и запускает фоновую синхронизацию индекса.

GET /api/update?url=https%3A%2F%2Fdocs.example.org%2Freglament.pdf

Пример ответа:

{
  "status": "accepted",
  "url": "https://docs.example.org/reglament.pdf"
}

Встраивание виджета

Разместите код перед закрывающим тегом </body>. 

<script src="https://chat.vbudushee.ru/widget" defer></script>
<div id="vchat-chat"></div>
  • defer обязателен, чтобы не блокировать загрузку страницы.
  • Контейнер div#vchat-chat обязателен, в него монтируется интерфейс виджета.
  • Используется единый скрипт: https://chat.vbudushee.ru/widget.
